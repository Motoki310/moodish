# デートレストラン提案サイト(プロトタイプ)

デートに特化した飲食店口コミサイトのうち、「お店を提案する」機能のプロトタイプです。
HTML / CSS / 素のJavaScriptのみで構成されており、バックエンドはありません。

## 構成

```
date-restaurant-proposal/
├── index.html      # 提案フォーム(ユーザー向け)
├── admin.html       # 入力データ一覧(管理者向け)
├── css/
│   └── style.css    # 桜色 x クリスタル(グラスモーフィズム)テーマ
├── js/
│   ├── app.js       # フォーム制御・提案結果の表示・データ保存
│   ├── admin.js      # 管理画面の一覧表示
│   └── data.js       # おすすめ店舗のダミーデータ
└── README.md
```

## 使い方

1. `index.html` をブラウザで開く
2. 必須項目(目的・関係性/場所/予算/シーン/日時/ジャンル)と任意項目を入力し送信
3. ダミーデータからランダムに3件のおすすめ店舗が表示される
4. 送信内容はブラウザの `localStorage` に保存され、`admin.html` で一覧確認できる

## 現時点の制約(プロトタイプゆえの割り切り)

- おすすめ店舗は実際の検索・絞り込みは行わず、固定のダミーデータ(`js/data.js`)からランダムに3件表示している
- 「2人の最寄駅から中間地点を提案」は入力欄のみで、実際の中間地点計算ロジックは未実装
- データ保存先はブラウザのlocalStorageのみ(サーバー/DB未接続のため、他端末・他ブラウザとは共有されない)
- 管理画面に認証機能はない(プロトタイプのため誰でも閲覧可能)
